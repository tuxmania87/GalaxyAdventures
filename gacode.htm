Ab sofort wird in Nicks und Texten (Allybeschreibung etc.) kein HTML mehr
interpretiert!

Achtet beim Editieren von Texten darauf, dass ihr evtl. enthaltene HTML-Tags entfernt!

Verwendet werden sollte stattdessen:

[b][/b] - fett
[i][/i] - kursiv
[klein][/klein] - Schrift kleiner als normal
[gross][/gross] - Schrift groesser als normal
[norpg][/norpg] - Text wird als nicht-RPG gekennzeichnet
[farbe:FARBE][/farbe] - färbt eingeschlossenen Bereich in angegebene Farbe.
Erlaubt sind entweder in HTML übliche Farbnamen (black,red etc.) oder Farbcode in Hex-Format (#FFFFFF etc.)
[spieler:ID] - Wird ersetzt durch Nickname vom Spieler mit angegebener ID
[allianz:ID] - Wird ersetzt durch Allianzname von Allianz mit angegebener ID
[bild:URL] - Wird ersetzt durch Bild von angegebener URL ersetzt ( maximal 700 x 500 )
